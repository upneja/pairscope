# Pairscope

**The 23andMe of your relationship.** A free, AI-powered relationship health diagnostic grounded in 50+ years of peer-reviewed research.

Take a 10-minute assessment. Get a narrative report with visualizations, actionable insights, and conversation scripts — generated by Claude AI. No account required.

---

## What It Is

Pairscope is a full-stack web application that turns clinical psychometrics into something people actually want to read. Five validated research frameworks (Gottman, Attachment Theory, Big Five, CSI-4, Love Languages) are distilled into a single adaptive assessment. Your answers are scored client-side, then synthesized by Claude into a personalized narrative report.

The report is the product: prose that reads like a thoughtful expert wrote it specifically for you, paired with interactive Recharts visualizations and ready-to-use conversation scripts.

---

## Feature Highlights

- **Dual-mode assessment** — "In a Relationship" (~45 questions) and "Flying Solo" (~35 questions) with adaptive branching based on real-time dimension scores crossing clinical thresholds
- **Five validated frameworks** — Gottman Four Horsemen, ECR-R attachment dimensions, Big Five personality traits (relationship-critical subset), CSI-4 satisfaction index, Love Languages
- **AI narrative synthesis** — Claude receives only computed dimension scores (not raw answers); generates a multi-section report in personalized prose
- **Interactive report** — Radar charts, spectrum bars, emotional bank account meters built with Recharts
- **PDF export** — Full visual fidelity via html2canvas + jsPDF
- **Privacy-first** — No account, no database; all scoring runs client-side; session storage only

## Running Locally

```bash
git clone https://github.com/upneja/pairscope.git
cd pairscope/app
npm install

# Create .env.local and add:
# ANTHROPIC_API_KEY=sk-ant-...

npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
